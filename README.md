# AgriFlow - Farm Management System

AgriFlow is a comprehensive farm management application designed to help farmers track their crops, livestock, and finances efficiently.

## Local Setup Instructions

Follow these steps to run the application on your local machine:

### 1. Prerequisites
- **Node.js** (v18 or higher recommended)
- **npm** or **yarn**
- **Backend API**: Ensure you have access to the AgriFlow backend API.

### 2. Installation
Clone the repository and install the dependencies:

npm install
